# Игровые ассеты Global/EN

`catalog.json` — единственный владелец рецептов crop, контрольных сумм, ROI, safe tap и порогов.
`main.dock.png` нужен для безопасного открытия Dock; `dock.header.png` — для независимого
подтверждения названия и возврата по стрелке. Заголовок сам по себе не доказывает обычный Dock:
`dock.selection-confirm.png` исключает режим выбора кораблей до действия и после него; нажимать
эту кнопку capability не разрешает. `main.depot.png` даёт отдельный read-only признак главного меню.
Отобранные crops содержат только элементы UI, без профиля, валют, состава кораблей и чата.

SHA256 исходника и его размеры записаны отдельно для каждого варианта. Все четыре шаблона получены
из реальных кадров Global/EN размером 3840×2160 в необязательном локальном архиве `assets_raw/`:
главное меню, обычный Dock и целевой выбор корабля. Отрицательные заголовки взяты из кадров Depot
и Technology того же архива. Точные исходники определяются по SHA256, а не по именам файлов.
Полные кадры не поставляются и для сборки/тестов не требуются. Производные образцы в
`tests/fixtures/game` обезличены; их однотонный фон и масштабирование являются искусственными.

Воспроизведение выполняет `tools/assets/prepare_game_assets.py` через `uv run`; передай повторяемый
`--source` с исходниками, чьи SHA256 соответствуют каталогу и `tests/fixtures/game/provenance.json`.
Для полного локального архива команда из корня репозитория в PowerShell:

```powershell
$sourceArgs = @(Get-ChildItem -LiteralPath assets_raw -File -Filter *.png -Recurse | ForEach-Object { '--source'; $_.FullName })
uv run tools/assets/prepare_game_assets.py @sourceArgs
```

Скрипт проверяет все обязательные исходники, их формат, SHA256, размеры и рецепты до изменения
артефактов. Готовый комплект crops, каталога и контрольных fixtures публикуется через временные файлы
на том же томе с резервными копиями; при исключении публикации прежние файлы восстанавливаются,
новые удаляются. Если восстановлению мешает отдельная ошибка файловой системы, резервные копии
сохраняются по пути из сообщения отказа. Это восстановление при исключениях, а не гарантия
пережить принудительное завершение процесса или сбой ОС. Пути входа не сохраняются.
Перед новым вариантом визуально проверь crop и отрицательные образцы, затем обнови provenance.
Обезличенные negative fixtures заголовков Depot/Technology защищают от общего оформления стрелки;
selection fixtures сохраняют только Dock header и кнопку Confirm, без кораблей/счётчиков аккаунта.
